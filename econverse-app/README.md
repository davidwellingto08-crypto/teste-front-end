# Teste Front-End Jr — Econverse

Projeto desenvolvido como parte do desafio técnico para a vaga de Desenvolvedor Front-End Jr da Econverse.

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- Sass (SCSS)
- HTML5
- CSS3

## Funcionalidades

- Exibição dinâmica de produtos.
- Consumo de dados de uma API JSON.
- Navegação entre produtos por setas.
- Modal com detalhes do produto selecionado.
- Formatação de preços em Real (BRL).
- Layout responsivo.

## Como executar o projeto

### Pré-requisitos

- Node.js
- npm

### Instalação

```bash
npm install
```

### Executar em desenvolvimento

```bash
npm run dev
```

Acesse: http://localhost:5173

### Compilar para produção

```bash
npm run build
```

Os arquivos de produção serão gerados na pasta `dist`.

### Pré-visualizar a versão de produção

```bash
npm run preview
```

## Fonte dos produtos

Os produtos são carregados do arquivo JSON disponibilizado pela Econverse:

https://app.econverse.com.br/teste-front-end/junior/tecnologia/lista-produtos/produtos.json
